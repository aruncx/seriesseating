# VAST Exam Seating Studio

A web tool for generating examination seating arrangements.
It runs entirely in your browser, and no data is uploaded anywhere.

## Features
- Upload the student list (Excel/CSV) and the exam timetable (DOCX/PDF)
- Set up exam rooms, benches and left/right batch pairing
- Generate room-wise seating with seat numbers
- Export WhatsApp images, a 5-page PDF, a poster, or print
